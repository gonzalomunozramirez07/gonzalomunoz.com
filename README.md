# gonzalomunoz.com

Personal website for Gonzalo Munoz.

## Overview

This repository contains a lightweight static website built with plain HTML,
CSS, and JavaScript. It is designed to be easy to customize and deploy on static
hosting platforms such as GitHub Pages, Netlify, or Vercel.

## Files

- `index.html` - page structure, content, and SEO metadata
- `styles.css` - responsive visual design and theme styles
- `script.js` - theme toggle and dynamic footer year
